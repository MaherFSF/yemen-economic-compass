## 🚀 Deployment Instructions

### Option 1: Manus Platform (Recommended)
1. Click **Publish** button in Management UI (top-right corner)
2. Site will be deployed to Manus hosting
3. Custom domain can be configured in Settings → Domains
4. SSL certificate automatically provisioned
5. Live within 2-3 minutes

### Option 2: External Hosting
If deploying to external hosting (Vercel, Netlify, Railway):
1. Connect GitHub repository
2. Set build command: `pnpm build`
3. Set output directory: `dist`
4. Configure environment variables (see .env.example)
5. Deploy
