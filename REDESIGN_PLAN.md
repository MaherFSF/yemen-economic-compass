# Yemen Economic Observatory - Complete Redesign Plan

## VISION: Evidence Engine for Yemen's Economy
Transform from "website with reports" to "verifiable economic intelligence system" that serves:
- **Citizens** (Arabic-first, plain language, practical relevance)
- **Policymakers** (rigor, scenarios, policy options)
- **Donors** (traceability, results tracking, risk flags)
- **Journalists/Researchers** (transparency, sources, reusable charts)

## Core Mission
Make Yemen's economic reality **understandable, verifiable, and actionable** through:
- Unified data covering 2010-2025 (15+ years rolling forward)
- Continuous updates (not static reports)
- Clear explanations of WHY things matter, HOW they connect, WHAT changed
- Credible policy options with trade-offs

## Phase 5: Evidence Transparency System
**Core Feature**: "Show me how you know this" button everywhere

### Implementation
- [ ] Add button to every statistic, chart, and claim
- [ ] Create modal that displays:
  * **Exact Sources**
    - Document IDs with clickable links
    - Publisher and publication date
    - Page numbers where data appears
  * **Extraction Details**
    - Snippets from original documents
    - How data was extracted (manual, API, OCR)
  * **Transformations**
    - Currency conversions applied
    - Deflation/inflation adjustments
    - Rebasing calculations
    - Aggregation methods
  * **Confidence Rating**
    - A = Audited/official + consistent across sources
    - B = Credible but partial or lagged
    - C = Indirect proxy / modelled / uncertain
    - D = Disputed or low reliability
  * **Alternative Sources**
    - Other estimates for same indicator
    - Why they differ
  * **What Would Change This**
    - What new evidence would alter conclusion
    - What assumptions are critical

### Data Provenance Ledger
- [ ] Create database table for all data sources
- [ ] Track: publisher, collection method, access path, license, update cadence, limitations
- [ ] Show provenance chain for derived indicators

### Contradiction Detector
- [ ] Flag conflicting values for same indicator/time/location
- [ ] Store both versions with labels
- [ ] Explain differences (methodology, coverage, political incentives, revisions)

### Version History
- [ ] Preserve "what was known when"
- [ ] Show revision history for corrected data
- [ ] Allow users to see data as it appeared at any past date

## Phase 8: Content & Data Quality

### Source Integrity (Non-Negotiable)
- [ ] Never invent facts, numbers, quotations, documents, or citations
- [ ] If cannot verify, say so plainly and label as unknown
- [ ] Every number must have:
  * Source (publisher, document, link, date)
  * Geography (Yemen, governorate if relevant)
  * Time coverage (month/year range)
  * Definitions/units (YER/USD, CPI base year, nominal vs real)

### Triangulation
- [ ] Prefer 2+ independent sources for high-stakes claims
- [ ] If sources conflict, show discrepancy and explain reasons
- [ ] Do NOT average conflicting sources

### Clear Labeling
Distinguish clearly:
- [ ] **Fact** (verified data)
- [ ] **Interpretation** (what it means)
- [ ] **Hypothesis** (possible explanation)
- [ ] **Forecast** (projection with uncertainty)
- [ ] **Recommendation** (policy option with trade-offs)

### Context Always
- [ ] Yemen is conflict-affected with institutional fragmentation
- [ ] Data gaps are common
- [ ] Do not apply "textbook" equations without stating assumptions
- [ ] Explain limitations

### "Explain Like I'm Busy" Summaries
- [ ] 5 lines maximum for top summary
- [ ] Expandable depth for experts
- [ ] Plain language (Arabic and English)
- [ ] No jargon without definitions

## Design Principles (Nano Banana Approach)

1. **Visual Storytelling**: Every page tells a story with data, not just displays numbers
2. **Audience-First**: Design for specific user needs, not generic visitors
3. **Evidence-Driven**: Every claim backed by visible, clickable sources
4. **Action-Oriented**: Provide options and scenarios, not just information
5. **Transparent**: Show methodology, uncertainty, limitations clearly
6. **Accessible**: Arabic-first, plain language, mobile-friendly
7. **Dynamic**: Update continuously based on new data and events
8. **Trustworthy**: Source integrity, no invented facts, clear confidence ratings
9. **Interconnected**: Link related data, show relationships, enable exploration
10. **Practical**: Focus on "so what?" and "what now?" not just "what happened?"
