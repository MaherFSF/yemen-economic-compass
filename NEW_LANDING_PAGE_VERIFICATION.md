## Technical Implementation

### CSS Variables (index.css)
```css
--yemen-red: oklch(0.45 0.20 15);        /* #CE1126 */
--yemen-green: oklch(0.45 0.15 150);     /* #007A3D */
--yemen-black: oklch(0.15 0 0);          /* #000000 */
--yemen-white: oklch(0.98 0 0);          /* #FFFFFF */
--yemen-red-light: oklch(0.60 0.18 15);  /* Lighter red */
--yemen-green-light: oklch(0.55 0.12 150); /* Lighter green */
```

### Tailwind Utilities
- `bg-[#CE1126]` - Red backgrounds
- `text-[#007A3D]` - Green text
- `border-[#CE1126]` - Red borders
- `from-[#CE1126] via-[#007A3D] to-black` - Gradients

### Component Structure
- **Home.tsx:** 400+ lines, fully self-contained
- **Sections:** Hero, Stats, Indicators, Features, Dual System, Branding, CTA, Footer
- **Icons:** lucide-react (16 unique icons)
- **Animations:** Scroll-based parallax, hover effects, bounce indicator
