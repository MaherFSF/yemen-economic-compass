# REFERENCE IMAGE ANALYSIS - DESIGN & DATA REQUIREMENTS

Based on the 45 reference images provided, here are the key design patterns and data visualization standards to implement:

## DESIGN PATTERNS

### 1. Professional Dashboard Layouts
- Clean, grid-based layouts with clear visual hierarchy
- Consistent spacing and padding
- Professional color schemes (blues, greens, grays)
- Clear section headers with icons
- Responsive card-based designs

### 2. Data Visualization Standards
- **Charts must have:**
  - Clear titles and subtitles
  - Proper axis labels with units
  - Legends explaining all data series
  - Source citations at bottom
  - Interactive tooltips
  - Export/download options

### 3. Typography & Branding
- Professional sans-serif fonts
- Clear heading hierarchy (H1, H2, H3)
- Consistent branding colors
- Professional logos and icons
- Bilingual support (Arabic/English)

### 4. Interactive Elements
- Filterable data tables
- Year/region/actor selectors
- Interactive charts with zoom/pan
- Hover tooltips with details
- Export buttons for data

## DATA REQUIREMENTS

### Core Datasets Needed:
1. **Economic Indicators (2010-2025)**
   - GDP (annual)
   - Inflation rates (Aden vs Sana'a)
   - Exchange rates (parallel markets)
   - Poverty rates
   - Food insecurity numbers
   - IDP counts

2. **Aid Flows**
   - By donor (World Bank, IMF, Saudi, UAE, UN agencies)
   - By year
   - By sector
   - Funding gaps

3. **Banking System**
   - CBY Aden vs Sana'a operations
   - Commercial bank locations
   - Currency circulation
   - Reserve levels

4. **Actors/Stakeholders**
   - International donors
   - UN agencies
   - Regional powers
   - Yemeni authorities
   - Private sector (Hayel Saeed, etc.)

5. **Events Timeline**
   - Political events
   - Economic shocks
   - Humanitarian crises
   - Policy changes
